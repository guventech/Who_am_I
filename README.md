# Who Am I?

Honest 10-question adaptive Big Five sketch (**English only**, prototype).

## Commands (PowerShell)

```powershell
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm e2e
pnpm sim
pnpm content:report
```

Storage defaults to client-only. With consent, `/api/storage` uses an in-memory store locally; set Convex env vars after `npx convex dev` (confirm EU region — see §14 in the brief).

Progress and standing decisions: [`REPORT.md`](REPORT.md). Product briefs stay local and are not published.
